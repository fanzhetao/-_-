时尚百货城自动化客户端 v1.1.1（Windows x64 便携版）

1. 将压缩包完整解压到可写目录，不要直接在压缩包内运行。
2. 启动 MuMu 模拟器 12，并确保 ADB 可用。
3. 游戏打开后须使用 9:16 竖屏分辨率（打开游戏前的模拟器桌面分辨率不限）：
   - 720×1280
   - 1080×1920（1080p）
   - 1440×2560（2K）
   - 2160×3840（4K）
4. 双击 FashionMallClient.exe，填写账号、密码和目标区号后开始运行。

客户端不需要另行安装 Python 或 Python 包。电脑桌面支持 1920×1080、
2560×1440 和 3840×2160，并会根据 Windows DPI 自动调整界面大小。

注意：
- 仍需用户自行安装 MuMu 模拟器 12 和游戏。
- 账号密码会明文保存在程序目录下的 runtime/config/ 中。
- 请将整个程序目录放在仅自己可访问的位置。
- 如果 Windows SmartScreen 提示未知发布者，请先核对压缩包来源；当前程序未进行商业代码签名。
